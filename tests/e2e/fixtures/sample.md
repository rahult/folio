# Sample plan

A short document the end-to-end checks open. It has three headings, a
paragraph under each, and one list, so the outline and the review keys have
something to point at.

## Goal

Ship the smallest change that proves the loop works end to end.

## Steps

1. Build the app from the checkout.
2. Launch it in a throwaway home folder.
3. Drive it the way a person would.

## Risks

The checks read the accessibility tree, so a renamed button fails a test
before it confuses a person.

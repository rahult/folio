# Folio — Design Context

### Users
Writers, engineers, and note-takers drafting Markdown on macOS who want a
focused, Typora-style writing environment: open a file, write, see it rendered
beautifully as they type, save. The job to be done is *writing without
friction* — the interface should disappear behind the text.

### Brand Personality
Calm, precise, crafted. The app should feel like a well-made writing tool
(iA Writer, Typora) — quiet confidence, nothing flashy. Emotion to evoke:
composure and focus. Anti-references: dashboard-y dev tools, neon-on-dark
"hacker" aesthetics, cluttered note apps with sidebars and panels.

### Aesthetic Direction
Refined editorial minimalism. A warm paper-tinted canvas, generous margins,
editorial serif for prose (Newsreader), a quiet modern sans for chrome
(Instrument Sans), real monospace reserved for code (JetBrains Mono). Warm
neutrals tinted toward paper; a single restrained oxblood-red accent for
links and interactive elements. Light theme, meticulously executed. No cards,
no panels, no gradients, no glow — hierarchy through typography and space.

### Design Principles
1. **The text is the interface** — chrome is minimal, quiet, and gets out of
   the way; the rendered document is the hero.
2. **Editorial typography first** — a real type scale, fluid sizing, serif
   prose; never system defaults.
3. **Warm, tinted neutrals** — no pure black/white; every neutral leans
   toward the paper hue.
4. **One accent, used sparingly** — oxblood red for links, focus, and primary
   actions only.
5. **Restraint over decoration** — if an element doesn't help writing or
   reading, it doesn't ship. Motion is subtle (fast ease-out fades), never
   bouncy, and respects reduced-motion.

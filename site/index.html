Markdown, rendered as you write it.

One page, no split panes. Folio is a small native editor for people who write in Markdown, and a review window for the plans your coding agent writes. Free and open source.

For writing

The text is the interface. Everything else steps out of the way until you ask for it.

Live rendering, real Markdown underneath

Headings, emphasis, lists, tables, code, quotes, links, and images render inline as you type. Press ⌘/ and the same page becomes plain Markdown, with your caret where you left it. Press it again to come back.

Focus and typewriter modes

Focus Mode dims every paragraph except the one you are in. Typewriter Mode keeps the line you are typing at a fixed height on the screen so your eyes never chase the caret. They compose.

Five themes, one typeface

Paper is warm and quiet; Manuscript is a deeper cream with brown ink for long reading; Newsprint is high contrast for bright rooms. Night is dark without being black, and Slate is a cool blue-grey dark with a copper accent. All five set prose in Newsreader, and the choice is remembered.

Export that looks like the page

File → Export writes one self-contained HTML file: highlighted code, Mermaid diagrams as SVG, your images and the typefaces embedded. Export → PDF prints the same rendering, and Export → Word writes a .docx with real heading styles, lists, tables, and images. All three are built from the Markdown, so the result never depends on what was on screen.

A proper desktop citizen

Native menus and file dialogs, a dirty dot in the title, Open Recent, and session restore that reopens your last file at the same caret and scroll position. Make it the default app for .md from the File menu. Updates install themselves.

For reviewing what your agent wrote

Coding agents produce plans, specs, and docs in Markdown, and you end up reading them as a diff in a terminal. Folio is the other half of that loop: a window that stays on top, shows what changed, and sends your notes straight back.

you /folio docs/plan.md

$ folio review --wait --agent claude docs/plan.md

waiting for your verdict in Folio…

# Review feedback: plan.md

Verdict: changes requested (2 annotations)

## 1. Replace "ship to all users at once"

Suggested replacement: 10% canary for a day, then 100%.

claude Updated the rollout section. Resubmitting.

plan.md live

Rollout

Ship to all users at once. Ship to 10% of users for a day, then everyone. Watch error rate and p95 latency before widening.

Roll back by flipping the flag, not by redeploying. Say who owns the flag during the canary.

claude waiting, 2 annotations Request changes✓ Approve

What changed, at a glance

While the window floats, Folio watches the file. Each rewrite reloads in place with additions washed green and removals shown struck through. Your own unsaved edits are never clobbered.

Annotate with single keys, then send

The page turns read-only while the agent waits. Move between blocks with j and k, press c to comment, d to delete, r to suggest a replacement, a for looks good, Enter to send. The feedback reaches the agent's terminal as structured Markdown with line numbers.

Ask for it, or not

The /folio skill teaches Claude Code, Codex, and other agents the loop. It only runs when you type it. Without the skill, folio review plan.md from any shell opens a floating window and keeps watching the file.

Every version, kept

Revision History archives each on-disk version of a reviewed file and diffs any two, so you can see exactly what the agent did between its first draft and its fourth.

Install the skill once. It is user-invoked only.

git clone https://github.com/rahult/folio && cp -r folio/skills/folio ~/.claude/skills/

The CLI exits 0 on approve, 2 on changes requested, 3 if the review is still open, so an agent can branch on the result.

Also on board

  • Quick Open (⌘P) fuzzy-finds any Markdown file in the project, recents first, without a sidebar.
  • Authorship tints the words an agent wrote, and the ones it rewrote after your feedback, so your own edits stand out untinted.
  • Tabs keep several documents in one window, each with its own unsaved edits, caret, and scroll.
  • Reading panel with an outline, per-section reading time, and a takeaway saved beside the document.
  • Mermaid diagrams render inline from fenced blocks; click Edit to see the source.
  • Relative images resolve against the file, so ![](img/a.png) just works.
  • Link navigation ⌘-clicks between Markdown files, with [[wikilinks]], heading targets, and [[ completion.
  • Resizable table columns by dragging the border.
  • Auto-reload when the file changes on disk, agent edits or git checkouts alike.
  • Float on Top pins any window above everything else at a compact size.
  • Copy for agent puts the document on the clipboard as clean Markdown.
  • Pipe in with agent … | folio --float - to review output straight from stdin.
  • Zoom the page with ⇧⌘= and ⇧⌘-.
  • Live word count in the status bar, and CRLF files come out clean.
  • No telemetry unless you opt in; nothing loads before you do.
  • Windows and Linux builds from the same source.

xattr -dr com.apple.quarantine /Applications/Folio.app

Features

Seamless WYSIWYG

Markdown renders inline as you type — headings, emphasis, lists, tables, code blocks, blockquotes, links, and images.

Source Code Mode

Flip between the rendered page and raw Markdown with a single keystroke (⌘/).

Native everything

Real native menus and file dialogs, dirty indicator, live word count — a proper desktop citizen.

Folio Pro

Export to HTML & PDF, Focus Mode, Typewriter Mode, and the Night and Newsprint themes — unlocked with an offline license key.

Editorial design

Warm paper canvas, Newsreader serif prose, one oxblood accent. Nothing between you and the sentence.

Tiny footprint

Built on Tauri with the system webview — a ~5 MB download, no bundled browser.

Download

Grab the latest build from GitHub Releases:

  • macOS — .dmg (Apple Silicon)
  • Windows — .msi / .exe
  • Linux — .AppImage / .deb

Installers are unsigned: on Windows, SmartScreen → More info → Run anyway. On macOS, if the app is refused as "damaged" after downloading, clear the quarantine flag once: xattr -dr com.apple.quarantine /Applications/Folio.app
